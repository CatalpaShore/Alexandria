> **[非アダルトのオンラインデモを試す →](https://catalpashore.github.io/Alexandria/)** · インストール不要。メディアウォール、検索、詳細、サンプル再生、3言語の字幕、特集、模擬視聴記録を体験できます。インポート、トランスコード、バックアップ、モデルサービスはセルフホストが必要です。素材は12本のオープン映画の資料と独自のテスト映像のみです。

> **18歳以上対象：本プロジェクトは、成人が自分のアダルトメディアライブラリを管理するためのものです。** 所持・利用する権利のあるコンテンツのみを取り込み、お住まいの地域で適用される規則を守ってください。リポジトリにはアダルト動画、アダルト作品のジャケット画像、ダウンロード用リソースは含まれません。README の画像と公開デモには、実在する非アダルトのオープン映画情報、CC BY の許諾画像、および明示した模擬視聴記録を使用しています。

Alexandria 18+ は、メディアウォール、プレイヤー、特集、視聴作品の選択、任意の AI アシスタント、個人の視聴記録をまとめたアプリです。黒と金のデザインを採用した、オープンソースの個人用メディアプラットフォームです。既存ライブラリの取り込み、字幕の互換性、ストレージ変更時の記録の引き継ぎを重視しています。

## 主な機能

- **ライブラリを眺める：** ポスターウォール、ショート動画表示、検索と絞り込み、ランダム表示、複数バージョンの集約、作品詳細。
- **既存のコレクションを取り込む：** ローカルディスクやマウント済み NAS を索引化し、NFO、JSON メタデータ、ポスター、字幕を読み込みます。手動修正も保持します。
- **字幕付きで再生する：** 直接再生、リマックス、トランスコード / HLS、外部・内蔵テキスト字幕の選択、文字コードの切り替え。
- **コレクションを整理する：** 特集と関係グラフ、お気に入り、プレイリスト、ハイライト、再生位置、プロフィール切り替え、統計。
- **次に観る作品を決める：** 「观影台」はローカルの記録を使い、AI 館長は任意で Ollama に接続できます。モデル未設定時は固定サンプルであることを明示します。
- **長期的に記録を残す：** 個人の視聴記録、バックアップ、バックグラウンドタスク、取り込み監査、ソース移行のプレビュー。

通常のメディアスキャンやローカルメタデータの取り込みは元ファイルを変更しません。手動取り込み、リネーム、ファイル整理には別の管理画面があります。移行前にバックアップを作成し、[移行ガイド（中国語）](docs/MIGRATION.md)を確認してください。本プロジェクトはメディアの整理・発見・視聴に重点を置いています。

## 機能の詳細

各節のリンクから操作手順・資料の例・問題の確認方法を開けます。[ドキュメント](docs/README.ja.md)では目的から探せます。

### 1. メディアウォール・検索・複数バージョン

- ポスターウォールとショート動画表示を切り替え、作品詳細からファイル情報、メタデータ、再生画面へ進めます。ランダムな作品探しも可能です。
- 出演者、ジャンル、監督、メーカー、レーベル、シリーズ、品番の接頭辞、ソースフォルダ、ファイル形式などで絞り込めます。お気に入りや視聴状況も条件に組み合わせ、検索候補から作品や特集に移動できます。
- 同じ作品の複数ファイルをまとめて表示し、再生するバージョンを選べます。表示上の集約であり、ディスク上のファイルを削除・結合する処理ではありません。

[操作手順](docs/USER_GUIDE.ja.md#media-wall)

### 2. 既存ライブラリとローカルメタデータ

- フォルダ構成全体を整理し直さずに、内蔵・外付けディスクやマウント済み NAS のフォルダを登録できます。スキャンはファイル情報を読み取って索引を作成し、通常は元ファイルの移動・リネーム・書き換えを行いません。
- 動画に隣接する NFO、`.media.json`、ポスター、字幕を読み込みます。同名 JSON は項目単位で NFO に優先し、既存の手動修正や取得済み外部メタデータを優先して、再スキャン時にも整理結果を保ちます。
- ポスターと通常の画像を区別し、作品のジャケットが画像ウォールに混在するのを防ぎます。メタデータ管理と品質チェックで欠落項目、競合、誤ったファイルの関連付けを確認できます。外部情報の補完には別途設定が必要です。

[操作手順](docs/USER_GUIDE.ja.md#library-import) · [ローカル資料の例](docs/USER_GUIDE.ja.md#metadata)

### 3. 再生・字幕・再生位置

- プレイヤーは再生位置の記録と、続きから観る機能に対応しています。ファイルとブラウザの能力に応じて直接再生、リマックス、トランスコード / HLS を利用します。メディアの解析と必要な変換には FFmpeg / FFprobe を使用します。
- 外部の SRT、ASS、SSA、VTT と、MKV / MP4 の内蔵テキスト字幕を選択できます。文字化けした場合は、字幕ファイルを書き換える前に文字コードを切り替えて確認できます。
- テキスト字幕はブラウザ向けの VTT に変換します。ASS / SSA の複雑な配置や演出は完全には保持せず、画像形式の字幕には未対応です。コーデック、音声トラック、端末の互換性はブラウザと FFmpeg に依存し、すべてのファイルの直接再生を保証するものではありません。

[操作手順](docs/USER_GUIDE.ja.md#playback) · [字幕と文字コード](docs/USER_GUIDE.ja.md#subtitles)

### 4. 特集とナレッジグラフ

- 出演者、テーマ / シリーズ、タグ、品番の接頭辞、監督、メーカー、レーベルから特集を開き、関連作品や別の分類へ探索を続けられます。
- 特集の検索、作品数・名前・更新順・ランダム順の並べ替えに対応します。関係グラフでは人物、作品、分類のつながりをたどれます。
- 表示できる情報は取り込んだメタデータによって変わります。公開リポジトリには網羅的な出演者データベースや出演者の写真を含めていません。自分の資料や外部情報の補完は別途設定してください。

[操作手順](docs/USER_GUIDE.ja.md#topics)

### 5. 「观影台」：候補から次の一本を選ぶ

- 「观影台」（視聴作品を選ぶ画面）は、ローカルの作品、お気に入り、視聴履歴、最近の取り込みから候補を整理します。素早く選ぶ、探索する、お気に入りから選ぶ、未視聴から選ぶといった入口があり、言語モデルは不要です。
- テーマ条件や二択の選択を通じて候補を絞り込みます。結果は「最合口味」（好みに近い）、「换点新意」（少し違うもの）、「大胆试试」（冒険してみる）に分かれます。
- 前回のセッションを続けたり、最近のセッションから条件を再利用・調整したりできます。このローカルの選択機能は、AI 館長のモデルによる会話とは独立しています。

[操作手順](docs/USER_GUIDE.ja.md#viewing-desk)

### 6. AI 館長：任意のローカルモデル連携

- 自分で用意した Ollama に接続し、会話モデルと埋め込みモデルを個別に設定して、手動でロード・アンロードできます。複数の会話、自然言語での検索、`@`・`/`・`#` による対象・意図・制約の指定に対応します。
- 接続後はライブラリのメタデータ、お気に入り、視聴記録を検索し、参照情報付きの推薦・特集・比較・要約カードを表示します。変更を伴う操作は確認カードで内容を確認できます。モデルの回答は参照情報と照らし合わせて確認してください。
- **モデルを有効にしていない場合は、非アダルトの固定サンプルを表示します。** 固定サンプルであり AI の回答ではないことを画面上に明示します。実際の推論は行わず、本物の会話履歴やライブラリにもサンプルを書き込みません。
- モデルの実行環境、モデルファイル、接続設定は同梱していません。外部サービスは初期状態で無効です。接続先をリモートに設定すると、対応する問い合わせや文脈情報がその接続先に送信されます。[設定ガイド（中国語）](docs/OPERATIONS.md)を参照してください。

[操作手順](docs/USER_GUIDE.ja.md#curator)

### 7. お気に入り・プレイリスト・視聴記録

- 観たい作品、繰り返し観る作品、特定テーマの作品をお気に入りとプレイリストで整理できます。再生位置、続きから観る項目、視聴済み状態、履歴を長期的に保存します。
- 「个人媒体手记」は最近の取り込み、続きから観る作品、視聴履歴、完了状況、好みの統計をまとめた画面です。視聴記録の削除や完了状態の変更もでき、主に視聴データの振り返りに使います。
- 個人プロフィールを切り替え、お気に入り、再生位置、プレイリストなどを分けて保持できます。企業向けの複数ユーザー権限管理を提供する機能ではありません。

[操作手順](docs/USER_GUIDE.ja.md#personal-library)

### 8. ハイライト：独立したクリップの保存

- プレイヤーで開始・終了時刻を指定するか、現在の再生位置を境界に設定し、1 秒から 30 分までのクリップを作成できます。
- 元動画を書き換えずに、別ファイルとして生成・保存します。完了したクリップは再生、ループ再生、ダウンロードができ、待機・処理中・失敗・再試行の状態も確認できます。
- 生成には参照可能な元動画、FFmpeg、書き込み可能な保存先が必要です。ハイライトの削除はそのクリップのみが対象で、元作品は削除しません。残したいクリップはバックアップにも含めてください。

[操作手順](docs/USER_GUIDE.ja.md#highlights)

### 9. 統計・取り込み監査・メンテナンス

- メタデータ品質チェックとライブラリ統計で整理の不足を確認できます。タスク関連の画面からバックグラウンド処理の進捗や失敗を確認できます。
- 整理待ちのローカルファイルを定期的に取り込み、バッチごとの結果、移動前と移動後のパスを確認できます。移動のロールバックは対象ファイルとパスが利用可能な場合に限られます。クラウドストレージからのダウンロードや新作の自動取得サービスではありません。
- 自動スキャンと、ファイルを移動する取り込み・整理操作は別の機能です。実際のライブラリを操作する前にプレビューと監査情報を確認し、独立したバックアップを保管してください。

[操作手順](docs/USER_GUIDE.ja.md#maintenance)

### 10. バックアップ・ソース移行・オフライン記録

- バックアップセンターでは保存先と対象範囲を設定し、手動・定期バックアップを実行できます。データベースのスナップショットだけでは全データのバックアップにならないため、ポスター、字幕、クリップなどの個別ファイルも保管してください。
- ディスクやマウント先の変更前にソースの変更をプレビューできます。ソースの分類・名前・相対パスが同じ場合はメディア ID を維持します。事前に作成したファイル全体のフィンガープリントでリネームや移動後の照合を補助し、判断が曖昧な重複は自動統合しません。
- ソースが切断されてもオフラインの記録を保持し、お気に入りや視聴履歴を直ちに削除しません。データベースの構造更新時には整合性のあるスナップショットを作成します。移行は独立したコピーで検証し、複数のサービスで同じデータベースを同時に使用しないでください。
- 大規模な NAS では、初回のファイル全体のフィンガープリント計算に時間がかかる場合があります。実際の全ライブラリの移行と大規模負荷は未検証です。準備と照合の制限は[移行ガイド（中国語）](docs/MIGRATION.md)を参照してください。

[操作手順](docs/USER_GUIDE.ja.md#backup-migration)

### はじめに使う機能

| 目的 | おすすめの手順 |
| --- | --- |
| 画面や再生を試したい | 独立した非アダルトデモを起動。設定済みのお気に入り・プレイリスト・履歴は閲覧でき、変更操作は制限されます |
| 整理済みのディスク / NAS を取り込みたい | ソース設定 → ローカル資料のスキャン → 品質確認 → 再生・字幕の確認 |
| 次に観る作品を決めたい | 「观影台」で候補の条件を選択。言語モデルは不要です |
| 自然言語で作品を探したい | Ollama を用意・設定し、AI 館長でモデルをロード |
| ストレージ交換・既存データの取り込み | 全データのバックアップ → 独立したコピーで作業 → ソース変更のプレビュー → 記録と再生の確認 |

### 表示言語

git clone https://github.com/CatalpaShore/Alexandria.git

### 独立した非アダルトデモ

<http://127.0.0.1:4312> を開きます。デモは実在する非アダルト映画の資料とテスト映像からなる独立ライブラリ、およびインメモリデータベースを使い、個人ライブラリの設定を読み込みません。閲覧、検索、特集、再生、字幕、館長のサンプルを体験できます。お気に入りや再生位置の書き込み、ディレクトリ設定、インポート、エクスポート、ファイル管理、モデルへのリクエストはサーバー側で制限します。設定済みのお気に入り、プレイリスト、視聴記録は展示用で、再起動時に初期状態へ戻ります。

コンテナでの起動やデプロイ上の制限は[デモの説明（中国語）](demo/README.md)を参照してください。正式なオンラインデモのドメインはまだありません。リポジトリとデプロイ先の確定後にリンクを追加します。

## 既存のリソースをすばやく接続

新規インストールの場合：

```sh
corepack pnpm@11.7.0 install --frozen-lockfile
pnpm doctor
# 読み取り専用プレビュー。複数のフォルダは --source を繰り返して指定：
pnpm setup:library --source "/absolute/path/to/media" --dry-run --lang ja
# パス確認後、新規環境に個人設定を作成：
pnpm setup:library --source "/absolute/path/to/media" --write --lang ja
pnpm build
pnpm start
```

スクリプトは `--lang zh-CN|en|ja` に対応します。フォルダの抽出確認と設定の作成のみを行い、メディアの移動・リネーム・変更やモデルのインストールは行いません。設定は Git 除外の実行データ内に保存し、既存のデータベースやソース設定は上書きしません。

起動済みの場合は、ホームの **ライブラリを接続 → フォルダを追加 → プレビュー確認 → バックアップしてスキャン開始** を使えます。JSON の編集は不要です。空のライブラリでは3ステップの案内を表示し、2ルート構成は詳細設定にまとめています。

フォルダ例、NAS / Docker、トラブルへの対処は[スタートガイド](docs/GETTING_STARTED.ja.md)を参照してください。

## コンテンツソースと再生互換性

| 機能 | 現在の対応範囲と制限 |
| --- | --- |
| ローカル・NAS | ローカルで読み取れる複数のディレクトリ（接続画面では最大32個）。SMB / NFS / クラウドドライブは先に OS でマウントし、コンテナでは読み取り専用メディアボリュームを使用 |
| メタデータ | 同名 `.nfo`（`movie` / `episodedetails`）、単一動画フォルダの `movie.nfo`。同名 `.media.json` は項目単位で NFO に優先。既存の手動修正と取得済み外部情報を優先 |
| ポスター | 同名 `-poster` / `.poster` / `.cover`、単一動画フォルダの `poster` / `folder` / `cover`。JPG / PNG / WebP に対応し、通常の画像ウォールから除外 |
| 外部字幕 | SRT / ASS / SSA / VTT。UTF-8・UTF-16 BOM を自動判定し、GB18030、Big5、Shift JIS、Windows-1252 を選択可能 |
| 内蔵字幕 | FFprobe で MKV / MP4 のテキスト字幕トラックを検出し、FFmpeg で VTT に抽出。画像字幕は別途 OCR が必要で、本アプリでは未対応 |
| 再生 | 直接再生・リマックス・トランスコード・HLS に対応。実際の互換性はブラウザと FFmpeg のコーデックに依存。ASS / SSA の複雑な演出はテキスト化時に失われます |
| ストレージ移行 | ソース変更をプレビューし、事前にデータベースをバックアップ。同じソースと相対パスで ID を保持し、ファイル全体のフィンガープリントで移動を照合。曖昧な重複は自動統合しません |
| 未実装 | WebDAV / Emby / Jellyfin のネイティブ接続、STRM ライブラリ、音声専用ライブラリ、クラウドドライブからのダウンロード、新作の自動取得 |

マウント済みフォルダの対応は、すべてのクラウドドライブやメディアサーバーのネイティブプロトコル対応を意味しません。切断したソースの記録は保持します。お気に入り・再生位置の引き継ぎと照合の制限は[移行ガイド（中国語）](docs/MIGRATION.md)を参照してください。

## Docker

```sh
mkdir -p media .local/docker-data
# Linux ではコンテナ内の node ユーザー（UID 1000）がデータディレクトリに書き込めるようにします。
ALEXANDRIA_MEDIA_DIR=/absolute/path/to/media docker compose up --build -d
```

初期設定ではホストのループバックアドレスにのみポート 4310 を公開します。コンテナではペアリング認証を有効にしており、ペアリングコードはローカルのサービスログで確認できます。メディアは読み取り専用、データディレクトリは書き込み可能です。Docker と Android 実機の検証状況は[検証記録（中国語）](docs/VERIFICATION.md)を参照してください。

## データ・プライバシー・サンプル

- メディア、データベース、モデル、認証情報、キャッシュ、個人設定は Git に含めません。実行時データの標準保存先は `.local/` で、`.env` も除外対象です。
- 公開ソースでは汎用的なパスと設定可能なディレクトリを使い、開発者のユーザー名、個人のディスク識別子、元ライブラリのパス、アカウント情報を含めていません。
- README の画像は確認済みのアイコンと非アダルトのスクリーンショットに限定し、SHA-256 で検証します。作業ツリーは `pnpm privacy:check`、Git インデックスは `pnpm release:check` で検査できます。
- [成人作品の文字メタデータサンプル（説明は中国語）](examples/adult-metadata/README.md)は、確認済みの品番、発売時のクレジット名、メーカー、日付を 3 件だけ含み、表示タイトルには中立的なアーカイブ名を使用します。`pnpm example:adult-metadata` で Git 除外ディレクトリに独立したテスト素材を生成できます。元作品の動画・ジャケット・成人画像は含まれず、デモにも自動追加しません。
- 外部メタデータサービスとモデル接続は各自で設定します。有効にすると設定先へ対応する問い合わせを送信します。詳細は[設定ガイド（中国語）](docs/OPERATIONS.md)を参照してください。

## よくある質問

**元のメディアファイルは変更されますか？** 通常のスキャン、ポスターの読み取り、ローカルメタデータの取り込みでは変更しません。手動取り込みとファイル整理は管理操作のため、事前にプレビューと監査情報を確認してください。

**モデルなしでも使えますか？** 閲覧、再生、整理は利用できます。館長には固定サンプルであることを明示して表示します。本物の会話にはモデルを設定し、最初の会話前に手動でロードしてください。

**付属の公開デモに実際の成人作品を使えますか？** 提供するデモは許諾された非アダルト映画素材と模擬データに固定されており、個人ライブラリの取り込み口はありません。個人用のデプロイと公開デモではデータの範囲を分けています。

**既存データを移行するには？** 全データをバックアップし、コピーで検証してください。構造更新時にはデータベースをバックアップします。複数のサービスで同じデータベースを同時に開かず、実際のデータで移行結果を確認してください。

**スマートフォンで使えますか？** レスポンシブ UI と Android ラッパーのコードを提供しています。セルフホストでは LAN アクセスとペアリング認証を設定できます。Android 実機とすべての端末・コーデックの組み合わせは、まだ検証が完了していません。
