## 1. 接入已有媒体库

1. 首次安装使用[接入脚本](GETTING_STARTED.md)，先运行只读预览；服务已运行时打开首页“接入媒体库”，或“更多工具 → 资源路径”。
2. 输入**服务器上**可读取的绝对目录。NAS / SMB / NFS 先挂载到系统；Docker 填容器内的目录，例如 **/media**。
3. 给来源设置稳定的分类与名称。换盘时保留这两个值，能帮助媒体记录与旧路径对应。
4. 点击“预览导入与迁移”，核对目录是否可读、保留记录数和空目录提示，再选择“备份并开始扫描”。
5. 回到媒体墙，等待扫描与后台媒体探测完成，检查少量作品的资料、播放和字幕，再扩大影库范围。

普通扫描只读使用影片，不整理源目录。断开来源会保留离线记录；不要通过删除数据库解决挂载错误。[NAS / Docker 路径示例](GETTING_STARTED.md)与[换盘流程](MIGRATION.md)另有说明。

<a id="metadata"></a>
## 2. 本地资料、海报与优先级

把资料放在影片旁边；以下为中性文件名示例，已有文件无需按这个示例统一改名。

~~~text
media/
└── Sample-001/
    ├── Sample-001.mp4
    ├── Sample-001.nfo
    ├── Sample-001.media.json
    ├── Sample-001-poster.jpg
    ├── Sample-001.zh.srt
    └── Sample-001.ja.srt
~~~

同名 **.media.json** 可使用以下字段；不需要每项都填写：

~~~json
{
  "title": "Sample Film",
  "description": "一部用于演示本地资料导入的影片。",
  "director": "Sample Director",
  "people": ["Sample Performer"],
  "collection": "Personal Collection",
  "tags": ["动画", "冒险"],
  "studio": "Sample Studio",
  "year": 2019
}
~~~

- NFO 支持 movie / episodedetails；单视频目录也可用 **movie.nfo**。JSON 按字段覆盖 NFO，已有手动修正和已完成的外部资料优先。
- 海报可用同名 **-poster / .poster / .cover**，单视频目录可用 **poster / folder / cover**，支持 JPG / PNG / WebP。
- 加入或更新本地资料后重新扫描，打开作品详情核对标题、人物、题材与海报。已有高优先级资料可能让旁车修改不生效，不要据此反复覆盖原文件。
- 没有旁车资料仍可索引与播放。外部资料补全需自行配置，见[配置说明](OPERATIONS.md)；本地导入本身无需联网。

<a id="media-wall"></a>
## 3. 媒体墙、搜索与多版本

1. 打开“媒体”，从搜索框输入片名、文件名、编号或人物名；也可选择搜索建议。
2. 展开筛选，按来源、目录、媒体类型、人物、题材、系列、收藏及观看状态组合缩小范围；手机上使用“筛选”按钮。
3. 点击卡片主体查看详情，点击播放按钮开始观看。详情中可核对文件编码、容量、时长、兼容状态和资料来源。
4. 同一作品有多个文件时，在版本入口选择实际文件；不同版本可能有不同字幕和兼容状态。聚合浏览不会合并或删除磁盘文件。
5. 查看关联作品时切换人物、系列或相似标签等维度；也可用随机浏览发现内容。

<a id="playback"></a>
## 4. 播放方式与继续观看

在播放器底部选择播放方式；先确认媒体源在线，再根据探测状态处理。

| 现象 / 需要 | 操作 |
| --- | --- |
| 浏览器支持当前文件 | 使用原文件直放；调整进度、倍速与音量 |
| 容器不合适、编码可用 | 选择封装转换，等待兼容文件准备完成 |
| 视频或音频编码不被浏览器支持 | 使用转码 / HLS；确认 FFmpeg 可用并留出磁盘空间 |
| 探测未完成或准备失败 | 查看“更多工具 → 播放兼容中心”和“任务与告警”，核对具体错误 |
| 源目录离线 | 恢复挂载后重试；转码不能替代缺失的原文件 |

播放进度属于当前用户，可从“我的”继续观看。转换需要后台处理时间，切换模式后等待状态完成。H.264 / MP4 是常见测试组合，不能据此推断所有浏览器都能直接播放所有编码。

<a id="subtitles"></a>
## 5. 字幕选择与乱码处理

1. 把外置字幕放在视频旁，用 **Sample-001.zh.srt** 等名称标注语言；支持 SRT、ASS、SSA、VTT。
2. 重新扫描后，在播放器顶部“字幕轨道”选择语言；选择关闭可隐藏字幕。
3. 出现乱码时，先从“字幕编码”选择 UTF-8、GB18030、Big5、Shift JIS 或 Windows-1252 等合适编码，再重新查看。带 BOM 的 UTF-8 / UTF-16 可自动识别，切换不改写原字幕。
4. MKV / MP4 内嵌文本字幕依赖 FFprobe 探测和 FFmpeg 提取，轨道在可用后出现在选择器中。

ASS / SSA 会转换为文本字幕，复杂排版和特效不完整保留；图片字幕需要单独 OCR。翻译和语音识别需要另行配置对应服务，读取现成字幕不需要语言模型。字幕语言、界面语言与作品资料语言分别控制。

<a id="topics"></a>
## 6. 专题与知识图谱

1. 打开“专题”，选择人物、系列、标签、导演、厂商等维度，搜索或调整排序。
2. 进入专题查看相关作品与资料；只有导入了对应字段，才会形成相应专题。
3. 切换到“知识图谱”，选择起始维度与节点，选择下一层关系后继续探索；可沿人物、题材等关系发现作品。
4. 图中节点少或没有连线时，先减少筛选、降低共同作品门槛，再检查本地资料是否包含人物和标签。

Demo 默认允许 1 部共同作品形成关联，便于展示小库。Demo 人物节点使用代表作配图，不是人物肖像；自部署的图谱规模取决于自己的资料。

<a id="viewing-desk"></a>
## 7. 用观影台挑选下一部

1. 打开“观影台”，按当前需要选择快速选片、探索、收藏或未看等入口。
2. 设置题材等条件；候选不足时减少限制，检查是否排除了近期观看内容。
3. 在成对候选中做选择，或从推荐候选继续探索，逐步缩小范围。
4. 查看“最合口味”“换点新意”“大胆试试”等结果，打开详情后播放；可继续已有会话或从近期会话调整条件。

观影台使用本地馆藏与记录，不要求先部署语言模型。公开 Demo 中涉及写入的新选择会被阻止，可浏览预设结果。[效果截图](../client/public/showcase/viewing-desk.png)

<a id="curator"></a>
## 8. 智能馆长与本地模型

**先了解界面：** 未接模型时直接打开“馆长”，切换左侧示例问题，查看推荐卡片和资料引用。“固定示例 · 非 AI 回答”是预先编写的说明，不会写入真实对话。

**使用自己的馆藏：**

1. 按[模型配置步骤](OPERATIONS.md#可选本地馆长)准备 Ollama、对话模型和向量模型；地址与名称以实际安装为准。
2. 更新私有配置并重启服务，进入馆长点击“重新检测连接”。
3. 手动加载模型，完成馆藏索引，再创建会话。
4. 从“推荐几部尚未看过的冒险题材作品”等问题开始；可用 @、/、# 选择实体、意图和约束，继续追问。
5. 核对回答里的资料引用，打开推荐卡片查看作品详情；有修改操作时先检查确认卡片。

模型并不随仓库安装。远程 Ollama 会收到相应查询与上下文，公开 Demo 不调用模型。[馆长示例截图](screenshots/curator-demo.png)

<a id="personal-library"></a>
## 9. 收藏、片单、观看记录与用户

1. 点击作品或专题上的收藏按钮，在“我的”查看收藏；作品收藏和专题收藏分别组织。
2. 使用加入片单入口选择或创建片单，再从“我的”进入片单管理内容。
3. 从继续观看、观看历史和个人媒体手记回顾记录；需要时修改已看状态或清理记录，先核对当前用户。
4. 点击顶部用户入口打开“用户管理”，新建或切换长期用户，各自保留收藏、片单和观看记录。

临时访客记录在离开访客或服务重启后清除，不适合长期保存。用户档案用于区分个人记录，不提供企业级账户权限隔离。Demo 展示固定的 6 个媒体收藏、3 个片单和 8 条观看记录，修改不会保存。

<a id="highlights"></a>
## 10. 截取与回看精彩片段

1. 播放原文件时点击剪刀图标，打开“截取高光”。
2. 输入名称，播放到合适位置，分别点击“设为起点”“设为终点”；也可直接输入秒数。范围为 1 秒至 30 分钟。
3. 先定位起点核对，再点击“保存片段”。
4. 在“我的高光”查看状态，完成后播放或下载；失败时检查原文件、FFmpeg 与片段存储目录，再使用“修复重试”。

片段独立保存，原影片不改写；删除高光只删除该片段。存储目录离线时先恢复挂载。公开 Demo 不执行截取任务。

<a id="maintenance"></a>
## 11. 统计、资料维护与任务

| 入口 | 使用方式 |
| --- | --- |
| 分析中枢 | 查看年份、题材、编码、容量及字段覆盖，定位需要整理的范围 |
| 元数据管理 | 先按状态缩小范围并核对作品，再进行已配置资料服务的补全；批量处理前检查目标集合 |
| 翻译管理 | 查看字幕 / 语音识别任务的阶段与队列；服务未配置时先处理配置问题 |
| 播放兼容中心 | 按兼容状态查看文件与处理队列，按需安排探测、封装转换或转码 |
| 任务与告警 | 查看失败原因、等待状态与处理进度，恢复依赖后再重试 |
| 自动入库 | 核对来源、目标及规则，先确认批次；查看审计记录，回滚前检查相关文件仍存在 |

普通扫描与会移动文件的入库操作不同；首次使用管理操作时从小批量开始。外部服务和存储是否就绪会影响任务，不能把占位展示视为任务已完成。

<a id="backup-migration"></a>
## 12. 备份、换盘与恢复

1. 从“更多工具 → 备份中心”选择目标目录，检查空间与可写性。
2. 选择需要的范围后“立即备份”，确认任务完成；需要定期备份时再设置频率。
3. 备份应覆盖数据库和独立附件，尤其是海报、字幕、片段与必要配置；按界面范围核对实际包含内容。
4. 换盘或恢复前停止使用同一数据库的服务，在副本上演练，按[迁移指南](MIGRATION.md)预览来源变化。
5. 验收作品数量、资料、收藏、播放进度、片单、片段引用与抽样播放后再切换正式使用。

数据库的升级快照不等于完整资源备份。完整指纹可辅助识别移动，重复内容有歧义时不自动合并；禁止两个服务实例同时打开同一个数据库。完整环境备份可能含私有配置，存放在自己的备份位置，不上传到公开仓库。

<a id="devices-language"></a>
## 13. 手机访问与语言

- 首页顶部选择中文、English 或日本語；选择保存在当前浏览器，不重写影片资料和目录。
- 手机访问时，先按[局域网配置](OPERATIONS.md#媒体与目录)启用 LAN 并保留配对认证，用服务器启动日志中的配对码完成配对。
- 手机底部导航对应媒体、专题、观影台、馆长与我的；窄屏下从“筛选”展开条件。
- 目录仍是服务器目录。手机的浏览器语言、网络与解码能力可能不同，先用少量文件验证播放与字幕。

<a id="demo"></a>
## 14. Demo 推荐体验顺序

运行 **pnpm demo:start** 后访问 <http://127.0.0.1:4312>：

1. 在媒体墙搜索 **Sintel**，查看真实年份、导演、配音人员和图片。
2. 打开播放器，切换中文 / 英语 / 日语字幕及编码；播放的是标注清楚的 12 秒兼容测试片。
3. 进入专题与知识图谱，沿人物和题材探索，再浏览观影台与“我的”里的预设记录。
4. 在馆长切换三个固定问题，点击电影卡片打开详情。
5. 打开顶部“素材来源与演示说明”，查看配图的 CC BY 许可与官方作品链接。

Demo 的数据库在内存中，重启恢复预设。导入、文件管理、模型和写入操作被服务端阻止；脱敏影库录像也不在非成人 Demo 中加载。[完整 Demo 说明](../demo/README.md) · [电影素材清单](DEMO_FILMS.md)

## 15. 常见问题的排查顺序

先检查**运行环境 → 来源挂载 → 扫描 / 探测状态 → 单文件播放 → 字幕轨道与编码 → 后台任务**。提供反馈时写清服务版本、部署方式、所选播放方式和复现步骤，去掉私人路径、凭据、配对码与媒体内容。
