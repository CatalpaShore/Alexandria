# 界面国际化 / UI internationalization / UI の国際化

- 默认 `zh-CN`，可选 `en`、`ja`；首页、访问认证页均可切换，浏览器保存选择。
- 源语言文案作为字典键，`client/src/i18n/en.json` 与 `ja.json` 提供翻译；未知键回退源文案，参数通过 `{{name}}` 插值。
- 在 React 组件中调用 `useLocale()` 订阅变化，再用 `t("文案")` 输出界面文字。依赖翻译结果的计算使用 `useLocalizedMemo(factory, dependencies)`，它会在切换语言时重新计算，并按普通 React Hook 规则检查依赖。`t` 在调用时读取当前语言，事件回调不必仅为 `t` 增加依赖，避免无关副作用重跑。
- 纯格式化工具从 `i18n/core` 导入 `t` / `getIntlLocale`，避免把组件依赖引入工具模块。Ant Design 的按钮、分页与空状态由根 `I18nProvider` 配置 locale。
- 共享展示常量使用运行时 getter 调用 `t`，避免模块初始化时固定语言。不要把作品资料、来源身份、路径、用户问题或解析业务关键字放进翻译函数。
- UI language is separate from metadata language, subtitle language, and model response language. Raw server diagnostics and user content are preserved. Missing maintenance translations fall back to Chinese.
- UI の言語、メタデータ、字幕、モデルの回答言語は別です。ユーザーの資料とサーバー診断は元の内容を保持します。未翻訳の保守説明は中国語にフォールバックします。

新增 / Adding a message / 文言の追加：

```tsx
useLocale();
const title = t("现有 {{count}} 条馆藏记录将保留", { count: records.length });
```

给两个 JSON 字典同时添加相同的源语言键，保留相同的参数名。`pnpm i18n:check` 校验键集合、参数一致性与字面量翻译调用；`pnpm test:unit` 验证默认语言、持久化异常、插值与源文案回退。浏览器测试涵盖语言切换、刷新、筛选保持和媒体源预览流程。
