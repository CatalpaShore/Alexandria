# 项目范围与代码归属

Alexandria 18+ 是独立维护的开源个人媒体平台，包含媒体墙、播放器、专题、观影台、可选馆长、个人记录、扫描与元数据、转码 / HLS、片单、收藏、用户档案、统计、备份和维护功能。

本项目自行编写的代码采用 MIT 许可证。第三方依赖、模型、媒体及图片不因主项目许可证而改变条款；具体声明见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) 与[资源说明](ASSETS.md)。

本项目没有引入 Peach 源代码或图片；README 的组织参考已在各语言版本中注明。

## 公开仓库的边界

- 代码、通用配置模板、独立测试与已审核的非成人展示资源可以提交。
- 实际影库、数据库、封面与人物照片缓存、模型、密钥、私人路径和个人资料表不进入 Git。
- 独立 Demo 使用真实非成人开放电影资料和模拟记录；少量成人文字元数据示例与 Demo 分开，不包含成人图片或原作品视频。
- 外部元数据与模型服务默认关闭，需由部署者自行配置。
- 界面国际化不翻译或修改用户的作品资料、目录身份与原始诊断数据。

发布前运行 `pnpm privacy:check`，暂存后运行 `pnpm release:check`，并人工核对第三方许可与计划公开的资源。
