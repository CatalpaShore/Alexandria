# 从已有文件夹开始

继续阅读：[完整功能使用指南](USER_GUIDE.md) · [播放方式](USER_GUIDE.md#playback) · [字幕与编码](USER_GUIDE.md#subtitles) · [文档导航](README.md)

[简体中文](GETTING_STARTED.md) · [English](GETTING_STARTED.en.md) · [日本語](GETTING_STARTED.ja.md)

Alexandria 18+ 是个人影库。第一次建议只接入一个包含少量影片的目录，确认播放与字幕后再扩展。只想体验界面，使用 `pnpm demo:start` 的独立非成人 Demo 即可。

## 1. 准备运行环境

安装 Node.js 22、pnpm 11.7.0、FFmpeg 与 FFprobe，在项目根目录执行：

```sh
corepack pnpm@11.7.0 install --frozen-lockfile
pnpm doctor
```

`doctor` 只检查环境，不安装软件、不启动服务、不读取数据库。缺少 FFmpeg 时先完成安装；首次未构建的提示可在后续 `pnpm build` 解决。

## 2. 选择接入方式

### 服务已经启动：使用网页引导

1. 首页顶部选择界面语言，点击“接入媒体库”。空影库也会显示开始使用的卡片。
2. 填写影片目录的绝对路径，可添加多个目录。来源名称与分类用于长期识别，换盘时保持不变；不必编辑 JSON。
3. 点击“预览导入与迁移”，确认每个目录可读取、将保留的记录数。不可读目录不能保存，空目录需要明确确认。
4. 点击“备份并开始扫描”。数据库先备份，随后建立索引；普通扫描不移动、改名或改写影片。
5. 返回媒体墙，打开一部作品测试播放、字幕轨道与字符编码。扫描状态可在顶部和“任务与告警”查看。

普通用户无需展开“双根目录布局”高级设置。它面向特定目录组织方式，保存后会替换通用媒体源配置。

### 首次安装：使用脚本

```sh
# 默认仅预览，可重复 --source；路径含空格时保留引号。
pnpm setup:library --source "/absolute/path/to/media" --dry-run
# 核对后，明确写入首次配置：
pnpm setup:library --source "/absolute/path/to/media" --write
pnpm build
pnpm start
```

默认打开 <http://127.0.0.1:4310>。更改 `.env` 的 `PORT` 后使用实际端口。脚本支持 `--lang zh-CN|en|ja`；在交互式终端直接运行 `pnpm setup:library` 可逐个输入路径，仍然只做预览。

脚本最多抽样 300 个目录项，显示视频、字幕和元数据数量，**不代表完整扫描结果**。写入只创建私有配置和缺失的 `.env`，不安装模型、不复制影片；已有 `.env` 保留。检测到已有数据库、媒体源配置或 Demo 模式会拒绝覆盖，此时改用网页引导。

默认设置写入被 Git 忽略的 `.local/data/library-sources.json`。自定义 `DATA_DIR` 时使用对应目录；不要把数据目录放在要扫描的媒体目录内。

## 3. 准备可识别的本地资料

以下是目录结构示例，文件不随项目分发：

```text
media/
└── Sample-001/
    ├── Sample-001.mp4
    ├── Sample-001.nfo
    ├── Sample-001.media.json
    ├── Sample-001-poster.jpg
    └── Sample-001.zh.srt
```

没有资料文件也可以索引与播放。本地海报和 NFO / JSON 无需联网；JSON 按字段覆盖 NFO，手动资料修正优先。字幕支持 SRT / ASS / SSA / VTT；播放器可选择编码。MKV / MP4 内嵌文本字幕依赖 FFprobe 与 FFmpeg；图片字幕未支持。

## 4. NAS 与 Docker 路径

| 部署方式 | 应填的路径 |
| --- | --- |
| 服务与影片在同一机器 | 该机器上的影片绝对路径 |
| NAS、SMB、NFS 或云盘挂载 | 先在服务所在系统挂载，再填写挂载目录 |
| Docker | 容器内的路径，如 `/media`；不是宿主机的路径 |
| 手机 / 其他电脑浏览 | 路径仍属于服务器，不是当前浏览器所在设备 |

仓库的 Compose 把 `ALEXANDRIA_MEDIA_DIR` 挂载到容器的 `/media`，并以只读方式使用。可参考 README 的 Docker 命令；多个挂载需要在 Compose 中显式添加，再从网页注册容器内路径。平台没有原生 WebDAV / Emby / Jellyfin 连接器。

## 5. 常见卡点

- **找不到目录：** 检查服务运行在哪台机器、容器挂载位置和读取权限。浏览器无法直接选取服务器文件夹，复制绝对路径即可。
- **脚本拒绝覆盖：** 已有影库使用网页的预览与备份流程。不要删除数据库来绕过检查。
- **扫描较久：** 首次会读取资料并计算完整文件指纹，NAS 大库可能较慢；先验证小目录，再扩大范围。
- **作品没有封面：** 检查同名海报与单视频目录命名规则，再看元数据质量页面；没有配置外部服务时不会自动联网补全。
- **字幕乱码 / 样式不一致：** 在播放器选择编码；ASS / SSA 转成文本后不保留复杂特效，图片字幕需要另行 OCR。
- **手机要求配对：** 使用服务本机终端的六位配对码。LAN 配置见[使用说明](OPERATIONS.md)。
- **没有模型：** 浏览、播放、整理与观影台可用；馆长用明确标注的固定示例展示交互。

换盘、移动根目录或恢复应用数据前，阅读[迁移指南](MIGRATION.md)。需要增加界面翻译时，参阅[国际化开发说明](I18N.md)。
