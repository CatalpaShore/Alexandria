# 既存のフォルダから始める

画面のプレビューは最大 300 件を抽出し、動画・字幕・資料の数を表示します。全件のスキャン結果ではありません。新規の空ライブラリでは、ファイル全体の指紋確認が終わる前にローカル資料と字幕を利用できます。既存ライブラリでは従来の慎重な移行照合を維持します。

同名字幕は動画と同じフォルダーのほか、`Subs` または `Subtitles` サブフォルダーにも配置できます（例：`Subs/Sample-001.zh-Hant.srt`）。同名の複数バージョンなど判別できない場合は自動で関連付けません。

WebDAV などのリモートストレージは、[rclone](https://rclone.org/commands/rclone_mount/) などでサービスの実行環境にマウントし、そのローカルパスを登録できます。`myremote` を設定して空のマウント先を作成した後、例として `rclone mount myremote: /absolute/path/to/mount --read-only` を実行します。プロセスを維持し、読み取り権限を確認してください。Docker では起動前にホストから読み取り専用でバインドします。これはネイティブ接続ではなく、シークや接続状態はストレージとマウントに依存します。初回の全ファイル指紋計算は通信量が大きくなるため、認証情報をリポジトリに保存しないでください。

続けて[機能ガイド](USER_GUIDE.ja.md)・[再生](USER_GUIDE.ja.md#playback)・[字幕](USER_GUIDE.ja.md#subtitles)・[ドキュメント](README.ja.md)を参照してください。

[简体中文](GETTING_STARTED.md) · [English](GETTING_STARTED.en.md) · [日本語](GETTING_STARTED.ja.md)

Alexandria 18+ は18歳以上向けの個人メディアライブラリです。まず少数の作品が入ったフォルダで再生と字幕を確認してから、全体を追加してください。個人のメディアを使わずに試す場合は、`pnpm demo:start` で非アダルトデモを起動できます。

## 1. 実行環境を準備

Node.js 22、pnpm 11.7.0、FFmpeg、FFprobe をインストールし、プロジェクトのルートで実行します。

```sh
corepack pnpm@11.7.0 install --frozen-lockfile
pnpm doctor
```

`doctor` は環境を確認するだけで、ソフトの導入・サービス起動・データベースの読み取りは行いません。不足するツールを先に導入してください。ビルド未作成の表示は後で `pnpm build` を実行すると解決します。

## 2. 接続方法を選ぶ

### 起動済みの場合：画面の案内を使う

1. ホーム上部で言語を選び、「ライブラリを接続」を開きます。空のライブラリには開始カードも表示します。
2. 動画フォルダの絶対パスを入力します。複数のフォルダを追加でき、JSON の編集は不要です。ディスク交換時もソース名と分類を維持してください。
3. 「取り込み・移動をプレビュー」で読み取り可否と保持する記録数を確認します。読み取り不可のフォルダは保存できず、空のフォルダには明示的な確認が必要です。
4. 「バックアップしてスキャン開始」を選択します。先にデータベースをバックアップし、索引を作成します。通常のスキャンでは動画を移動・リネーム・書き換えしません。
5. メディアウォールに戻り、作品の再生・字幕トラック・文字コードを確認します。進捗は上部と「タスクと通知」で確認できます。

通常は詳細設定の2ルート構成を使う必要はありません。この設定を保存すると、汎用のメディアソース設定が置き換わります。

### 新規インストールの場合：スクリプトを使う

```sh
# 読み取り専用プレビュー。複数のフォルダは --source を繰り返して指定します。
pnpm setup:library --source "/absolute/path/to/media" --dry-run --lang ja
# 確認後、明示的に初期設定を書き込みます。
pnpm setup:library --source "/absolute/path/to/media" --write --lang ja
pnpm build
pnpm start
```

<http://127.0.0.1:4310> を開きます。`.env` で `PORT` を変えた場合はその値を使用します。`--lang zh-CN|en|ja` に対応し、対話型ターミナルで `pnpm setup:library --lang ja` を実行するとパスを順に入力できます。この場合もプレビューのみです。

スクリプトは最大300項目を抽出し、動画・字幕・メタデータの件数を表示します。**全体スキャンの結果ではありません。** 書き込みでは個人設定と、存在しない場合のみ `.env` を作成します。既存の `.env` は保持し、モデル導入や動画コピーは行いません。既存のデータベース・ソース設定・デモモードを検出すると上書きを拒否するため、画面の案内を使ってください。

標準の保存先は Git 除外の `.local/data/library-sources.json` です。`DATA_DIR` 指定時はそのディレクトリを使います。アプリのデータをスキャン対象のフォルダ内に置かないでください。

## 3. ローカル資料と字幕

フォルダの例です。これらのファイルはプロジェクトには含まれません。

```text
media/
└── Sample-001/
    ├── Sample-001.mp4
    ├── Sample-001.nfo
    ├── Sample-001.media.json
    ├── Sample-001-poster.jpg
    └── Sample-001.zh.srt
```

付属資料がなくても索引化と再生はできます。ポスターと NFO / JSON はネット接続不要です。JSON は項目単位で NFO に優先し、手動修正を優先します。外部字幕は SRT / ASS / SSA / VTT と文字コード選択に対応。MKV / MP4 の内蔵テキスト字幕には FFprobe と FFmpeg が必要です。画像字幕は未対応です。

## 4. NAS と Docker のパス

| 実行環境 | 入力するパス |
| --- | --- |
| サーバーと動画が同じ機械 | その機械上の動画の絶対パス |
| NAS・SMB・NFS・クラウドドライブ | サーバーの OS で先にマウントし、そのパスを入力 |
| Docker | ホスト側ではなく `/media` などのコンテナ内パス |
| スマートフォン・別の PC から閲覧 | 閲覧端末ではなく、サーバー側のパス |

付属 Compose は `ALEXANDRIA_MEDIA_DIR` を読み取り専用の `/media` としてマウントします。起動方法は README を参照してください。複数のマウントは Compose に明示的に追加してから、そのコンテナ内パスをアプリに登録します。WebDAV / Emby / Jellyfin のネイティブ接続は未実装です。

## 5. つまずきやすい点

- **フォルダが見つからない：** サーバーの機械、コンテナのマウント、読み取り権限を確認してください。ブラウザから直接フォルダを選べないため、絶対パスを貼り付けます。
- **スクリプトが上書きを拒否する：** 既存環境は画面のプレビュー・バックアップ手順を使用してください。回避のためにデータベースを削除しないでください。
- **スキャンが遅い：** 初回は資料の読み取りとファイル全体の指紋計算を行います。大規模 NAS では時間がかかるため、少量から試してください。
- **ポスターがない：** 同名ファイルと単一動画フォルダの命名規則、メタデータ品質を確認してください。外部サービスを設定しない限り、ネットで自動補完しません。
- **字幕の文字化け・見た目の相違：** プレイヤーで文字コードを選択してください。ASS / SSA の複雑な演出はテキスト化で失われ、画像字幕には別途 OCR が必要です。
- **スマートフォンでペアリングが必要：** サーバーのターミナルに表示する6桁のコードを使用します。[LAN 設定（中国語）](OPERATIONS.md)を参照してください。
- **モデルがない：** 閲覧・再生・整理・作品選びは利用できます。館長は固定サンプルを明示して表示します。

保存先の変更や復元の前に[移行ガイド（中国語）](MIGRATION.md)を確認してください。翻訳の追加は[国際化の開発説明](I18N.md)を参照してください。
