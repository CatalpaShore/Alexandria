## Demonstration boundaries

The recording uses an already-configured environment. Curator conversations and automation depend on separately configured services. Speech recognition is unavailable in the displayed environment; automatic processing is off and no new task is started. Model output is real, with inference waits edited down. VS compares viewing candidates, not model benchmark scores.

Mobile footage demonstrates responsive layout and pointer operations, not a physical phone recording. Long-press triple speed is a feature explanation, not a demonstrated phone gesture. No highlight generation, translation, transcoding or ingestion job is submitted for this localization.

The regular self-hosted introduction selects the video, poster and caption track for the interface language, retaining playback position when switching. The non-adult demo does not render this video and rejects the entire /tour path, including direct and HEAD requests.
