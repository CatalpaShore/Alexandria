# Documentation

[简体中文](README.md) · **English** · [日本語](README.ja.md) · [Project home](../README.en.md)

Alexandria 18+ is a self-hosted personal media library. The English video localizes narration, captions and chapter labels over the redacted recording; the recorded interface remains in Chinese. The public demo uses real non-adult film metadata and mock activity. [Video version and chapters](VIDEO.en.md) · [Asset details, in Chinese](ASSETS.md)

## Suggested reading order

1. **Explore first:** [start the non-adult demo](../demo/README.md) → [follow the walkthrough](USER_GUIDE.en.md#demo).
2. **Connect your files:** [environment and first setup](GETTING_STARTED.en.md) → [sidecar naming](USER_GUIDE.en.md#metadata) → [playback](USER_GUIDE.en.md#playback) and [subtitles](USER_GUIDE.en.md#subtitles).
3. **Daily use:** find step-by-step operations in the [feature guide](USER_GUIDE.en.md).
4. **Storage and maintenance:** [migration](MIGRATION.md), [configuration](OPERATIONS.md), and [validation limits](VERIFICATION.md) currently have Chinese technical documentation.
