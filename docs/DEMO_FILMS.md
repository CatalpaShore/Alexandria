# Demo film artwork and metadata / 非成人电影素材清单

The demo uses factual metadata from real non-adult open films. Local playback is an original **12-second compatibility clip**, not the actual film; subtitles explain this and are not movie dialogue. Favorites, viewing records, playlists and most topic groupings are mock data. `Caminandes` is an actual series. No ratings or popularity figures are invented.

资料来自下表官方项目页及演职员表。简介为本项目撰写的简短概述；题材为演示分类。图片从官方项目页公开缩略图获取，存入仓库，运行时不连接图床。图片不是演员肖像，不用于暗示出品方背书。代码的 MIT 许可不改变图片的许可；保留图片及含图截图时，应同时保留本清单与署名。

All images were retrieved and visually reviewed on 2026-10-27. Project wordmarks and trademarks are not licensed by the code license. Artwork versions follow the linked project-specific license where published, otherwise the current Blender Studio website terms for its digital artwork; this does not relicense complete films, standalone soundtracks or excluded logos.
