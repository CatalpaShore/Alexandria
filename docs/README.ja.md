# ドキュメント

[简体中文](README.md) · [English](README.en.md) · **日本語** · [プロジェクトのホーム](../README.ja.md)

Alexandria 18+ は18歳以上向けのセルフホスト個人影庫です。日本語動画ではナレーション、字幕、チャプター説明を日本語化していますが、録画内の画面は中国語です。公開デモは実在する非アダルト映画の資料と模擬データを使用します。[動画の版とチャプター](VIDEO.ja.md)・[素材の説明（中国語）](ASSETS.md)

## おすすめの読む順番

1. **まず体験：** [非アダルトデモを起動](../demo/README.md) → [画面を順に試す](USER_GUIDE.ja.md#demo)。
2. **自分のフォルダを接続：** [環境確認と初回接続](GETTING_STARTED.ja.md) → [資料の命名](USER_GUIDE.ja.md#metadata) → [再生](USER_GUIDE.ja.md#playback)と[字幕](USER_GUIDE.ja.md#subtitles)。
3. **普段の操作：** [機能ガイド](USER_GUIDE.ja.md)で手順を確認。
4. **保存先と管理：** [移行](MIGRATION.md)・[設定](OPERATIONS.md)・[検証範囲](VERIFICATION.md)の技術資料は現在中国語です。
