# 機能の使い方

[ドキュメント](README.ja.md) · [简体中文](USER_GUIDE.md) · [English](USER_GUIDE.en.md) · **日本語**

<a id="library-import"></a>
## 1. 既存ライブラリの接続

1. 新規環境では[接続スクリプト](GETTING_STARTED.ja.md)で読み取り専用プレビューを行います。起動済みならホームの「ライブラリを接続」、またはツール内のリソースパスを開きます。
2. **サーバー側**で読める絶対パスを入力します。NAS・SMB・NFS は先に OS でマウントし、Docker では **/media** などのコンテナ内パスを指定します。
3. ソースの分類と名前を決め、ディスク交換時も同じ値を維持します。
4. 「取り込み・移動をプレビュー」で読み取り可否、保持件数、空フォルダの表示を確認し、「バックアップしてスキャン開始」を選択します。
5. スキャンとメディア解析の完了を待ち、数本の資料・再生・字幕を確認してから対象を広げます。

通常のスキャンは元ファイルを整理しません。切断したソースの記録はオフラインとして残ります。マウント不良を直すために DB を削除しないでください。[パスの例](GETTING_STARTED.ja.md)・[移行手順（中国語）](MIGRATION.md)

<a id="metadata"></a>
## 2. ローカル資料とポスター

資料は動画の隣に置きます。以下は中立的な例で、既存ライブラリ全体のリネームは不要です。

~~~text
media/
└── Sample-001/
    ├── Sample-001.mp4
    ├── Sample-001.nfo
    ├── Sample-001.media.json
    ├── Sample-001-poster.jpg
    ├── Sample-001.zh.srt
    └── Sample-001.ja.srt
~~~

同名の **.media.json** には次の項目を指定できます。すべて必須ではありません。

~~~json
{
  "title": "Sample Film",
  "description": "ローカル資料取り込み用の中立的な例。",
  "director": "Sample Director",
  "people": ["Sample Performer"],
  "collection": "Personal Collection",
  "tags": ["アニメーション", "冒険"],
  "studio": "Sample Studio",
  "year": 2019
}
~~~

- NFO は movie / episodedetails に対応し、動画が1本のフォルダでは **movie.nfo** も使えます。JSON は項目単位で NFO より優先し、既存の手動修正と取得済みの外部資料を優先します。
- 同名の **-poster / .poster / .cover**、単一動画フォルダの **poster / folder / cover** に対応します。画像形式は JPG・PNG・WebP です。
- 資料を追加して再スキャンし、作品詳細で確認します。優先度の高い資料がある場合、付属ファイルの変更が上書きされないことがあります。
- 付属資料がなくても索引化と再生は可能です。ローカル取り込みはネット不要で、外部補完には別途[設定（中国語）](OPERATIONS.md)が必要です。

<a id="media-wall"></a>
## 3. メディアウォール・検索・複数バージョン

1. メディアを開き、作品名・ファイル名・識別番号・人物名を検索します。候補から関連項目に移動できます。
2. ソース、フォルダ、種類、人物、ジャンル、シリーズ、お気に入り、視聴状態を組み合わせて絞ります。スマートフォンではフィルターを展開します。
3. カードから詳細を開くか、再生ボタンで視聴します。詳細で形式・容量・長さ・互換性・資料の出典を確認できます。
4. 同じ作品に複数ファイルがある場合は、再生する版を選びます。字幕や互換性はファイルごとに異なり、まとめて表示してもディスク上のファイルは統合・削除されません。
5. 関連作品を人物・シリーズ・タグから探すか、ランダム表示を使います。

<a id="playback"></a>
## 4. 再生方式と続きから視聴

プレイヤー下部の再生方式を選びます。変換前にソースがオンラインであることを確認してください。

| 状態 | 操作 |
| --- | --- |
| ブラウザがファイルに対応 | 元ファイルを再生し、位置・速度・音量を調整 |
| コンテナだけが非対応 | 再多重化を選び、準備を待つ |
| 映像・音声コーデックが非対応 | トランスコード / HLS を利用し、FFmpeg と空き容量を確認 |
| 解析待ち・準備失敗 | 互換性センターとタスク画面で原因を確認 |
| ソースがオフライン | 先にマウントを復旧する |

再生位置は現在のユーザーに保存され、個人ページから再開できます。変換には時間がかかります。H.264 / MP4 の確認だけで全ブラウザ・全形式への対応を判断しないでください。

<a id="subtitles"></a>
## 5. 字幕トラックと文字コード

1. SRT・ASS・SSA・VTT を動画の隣に置き、**Sample-001.ja.srt** などの言語接尾辞を付けます。
2. 再スキャン後、プレイヤー上部で字幕を選びます。非表示を選ぶと字幕を消せます。
3. 文字化けしたら UTF-8・GB18030・Big5・Shift JIS・Windows-1252 などの文字コードを選び直します。BOM 付き UTF-8 / UTF-16 は自動判別し、選択変更で元字幕を書き換えません。
4. MKV / MP4 の内蔵テキスト字幕は FFprobe の解析と FFmpeg の抽出後に選択できます。

ASS / SSA の複雑なレイアウトや効果はテキスト変換で完全には保持しません。画像字幕は別途 OCR が必要です。翻訳・音声認識には対応サービスを別途設定します。既存字幕の読み込みには言語モデル不要です。表示言語・資料言語・字幕言語は別設定です。

[プレイヤーの画像](screenshots/player-subtitles.png)・[互換性の範囲](../README.ja.md#コンテンツソースと再生互換性)

<a id="topics"></a>
## 6. 特集とナレッジグラフ

1. 特集で人物・シリーズ・タグ・監督・制作元などを選び、検索や並べ替えを行います。
2. 特集を開いて関連作品を確認します。対応するメタデータがない項目は作成されません。
3. グラフに切り替え、開始する分類とノードを選び、次の関係を指定して探索します。
4. ノードや線が少ない場合は、条件を減らし、共通作品数のしきい値を下げ、人物・タグの資料を確認します。

小規模デモの初期しきい値は1作品です。人物ノードは代表作品の画像を使い、本人の肖像ではありません。自分のグラフは取り込んだ資料に応じて構成されます。

[特集の画像](../client/public/showcase/topics.png)・[グラフ](../client/public/showcase/knowledge-graph.png)

<a id="viewing-desk"></a>
## 7. 观影台で次の一本を選ぶ

1. 观影台を開き、クイック選択・探索・お気に入り・未視聴などから開始します。
2. ジャンルなどの条件を設定します。候補が足りなければ条件や最近視聴した作品の除外を見直します。
3. 2つの候補から選択するか、候補をたどって絞り込みます。
4. 好みに近い候補・新しい候補・冒険的な候補を確認し、作品詳細から再生します。既存セッションの再開や最近の条件の調整もできます。

ローカルの作品と記録を使うため、言語モデルは不要です。公開デモは書き込みを伴う新しい選択を制限しますが、既定の結果は閲覧できます。[画面例](../client/public/showcase/viewing-desk.png)

<a id="curator"></a>
## 8. 館長とローカルモデル

**画面を試す：** モデル未接続でも館長を開き、左側の質問を切り替えてカードと引用を確認できます。「固定サンプル・AI の回答ではありません」は事前に用意した説明で、実際の会話には保存しません。

**自分の作品で使う：**

1. [モデル設定（中国語）](OPERATIONS.md#可选本地馆长)に沿って Ollama・会話モデル・埋め込みモデルを準備します。実際の接続先と導入済みモデル名を使用します。
2. 個人設定を更新してサービスを再起動し、館長で接続を再確認します。
3. モデルを手動で読み込み、作品索引の準備後に会話を作成します。
4. 「未視聴の冒険作品を何本か紹介して」などから始め、@・/・# で対象や条件を指定し、追加質問を行います。
5. 引用と作品詳細を確認します。変更の提案がある場合は確認カードを読んでから実行します。

モデルはリポジトリと一緒には導入されません。リモート Ollama には問い合わせと関連情報が送信されます。公開デモはモデルを呼び出しません。[館長の画像](screenshots/curator-demo.png)

<a id="personal-library"></a>
## 9. お気に入り・プレイリスト・履歴・ユーザー

1. 作品や特集のお気に入りボタンを押し、個人ページで確認します。作品と特集のお気に入りは分けて整理されます。
2. プレイリスト追加から既存リストを選ぶか新規作成し、個人ページで内容を管理します。
3. 続きから視聴・履歴・視聴記録を確認します。履歴の削除や視聴済み変更の前に現在のユーザーを確認してください。
4. 上部のユーザー管理から長期ユーザーを作成・切り替えます。お気に入り・リスト・視聴記録はユーザー別に保持します。

一時ゲストの記録はゲストを離れるか再起動すると消えます。ユーザーは個人記録の区別用で、企業向け権限管理ではありません。デモは作品のお気に入り6件・リスト3件・視聴記録8件を用意し、変更は保存しません。

## 10. ハイライトの保存と視聴

1. 元動画の再生中にはさみボタンを押します。
2. 名前を入力し、現在位置を開始・終了として設定するか秒数を入力します。長さは1秒から30分です。
3. 開始位置に移動して確認し、クリップを保存します。
4. 「我的高光」で状態を確認し、完了後に再生・ダウンロードします。失敗時は元ファイル・FFmpeg・保存先を確認して再試行します。

クリップは独立保存し、元動画は書き換えません。ハイライトを削除しても元作品は残ります。保存先が切断されている場合は先に復旧します。公開デモでは切り出しを実行しません。

<a id="maintenance"></a>
## 11. 統計・資料・タスクの管理

| 入口 | 使い方 |
| --- | --- |
| 分析画面 | 年・ジャンル・コーデック・容量・項目の充足状況を確認 |
| 元数据管理 | 状態で絞り、対象作品を確認してから設定済みサービスで補完 |
| 翻译管理 | 字幕・音声認識の段階とキューを確認し、必要なサービスを準備 |
| 播放兼容中心 | 互換性で絞り、解析・再多重化・トランスコードを必要に応じて実行 |
| タスクと通知 | エラーと待機理由を確認し、依存先の復旧後に再試行 |
| 自动入库 | ソース・移動先・規則・バッチを確認し、監査記録とファイルの存在を確認してからロールバック |

通常のスキャンとファイル移動を伴う取り込みは別操作です。初回の管理操作は少量から試してください。キューやサンプル表示は処理完了を意味しません。

<a id="backup-migration"></a>
## 12. バックアップ・ディスク交換・復元

1. ツールのバックアップ画面で保存先、空き容量、書き込み権限を確認します。
2. 範囲を選んで即時バックアップを実行し、完了を確認します。必要なら定期実行を設定します。
3. DB に加え、ポスター・字幕・クリップ・必要な設定など独立ファイルも対象にします。各範囲の実際の内容を確認してください。
4. ディスク交換や復元の前に DB を使うサービスを停止し、コピーで試してから[移行手順（中国語）](MIGRATION.md)を進めます。
5. 作品数・資料・お気に入り・再生位置・リスト・クリップ参照・抽出した作品の再生を確認して切り替えます。

アップグレード時の DB スナップショットは全資料のバックアップではありません。指紋による移動追跡でも曖昧な重複は自動統合しません。同じ DB を複数サービスで同時に開かないでください。環境全体のバックアップには個人設定が含まれる場合があるため、非公開の場所で管理します。

<a id="devices-language"></a>
## 13. スマートフォンと言語

- 上部で中文・English・日本語を切り替えます。ブラウザが選択を記憶し、作品資料やソース識別は変更しません。
- LAN を有効にし、ペアリング認証を維持します。サーバーのログにあるコードで接続してください。[ネットワーク設定（中国語）](OPERATIONS.md#媒体与目录)
- スマートフォン下部はメディア・特集・观影台・館長・個人ページの入口です。狭い画面ではフィルターを展開します。
- 入力するパスはサーバー側です。ブラウザやデコード能力が異なるため、端末ごとに少数の作品で再生と字幕を確認してください。

<a id="demo"></a>
## 14. おすすめのデモ体験順

**pnpm demo:start** を実行し、<http://127.0.0.1:4312> を開きます。

1. **Sintel** を検索し、実際の年・監督・声優・画像を確認します。
2. 明示された12秒の互換性テスト映像を再生し、中国語・英語・日本語字幕と文字コードを切り替えます。
3. 特集とグラフをたどり、观影台と個人ページの既定データを閲覧します。
4. 館長の3つの固定質問を切り替え、映画カードから詳細を開きます。
5. 上部の出典説明から画像の署名・CC BY ライセンス・公式作品へのリンクを確認します。

DB はメモリ内にあり、再起動で初期状態に戻ります。取り込み・ファイル管理・モデル呼び出し・書き込みはサーバーが制限します。ぼかし処理済みの個人影庫動画も非アダルトデモでは読み込みません。[デモの詳細](../demo/README.md)・[映画の出典](DEMO_FILMS.md)

## 15. 問題の切り分け

**実行環境 → マウント → スキャン・解析 → 1ファイルの再生 → 字幕と言語コード → タスク** の順に確認します。報告には版・実行環境・再生方式・再現手順を記載し、個人パス・認証情報・ペアリングコード・メディア本体を除いてください。
