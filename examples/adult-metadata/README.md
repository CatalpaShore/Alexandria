# 18+ 私有部署文字示例

此目录只保存最小事实字段，用于说明番号、发行时署名、片商和发行日期的展示。不是影片目录库，不提供视频、封面、剧情文案或下载链接。显示标题“作品档案 · 番号”是本项目的示例名称，不是原片名。

`catalog.json` 的 3 条记录于 2026-10-27 对照 S1 官方作品页核实。日期为官网列出的发行日期；源站可能区分实体发行与线上配信，不能据此推定所有渠道日期相同。来源页为 18+ 内容，不作为图床，也不会由 Demo 自动访问。

运行 `pnpm example:adult-metadata` 后，在 `.local/adult-metadata-example` 生成原创色块视频、原创抽象 PNG 和 NFO。视频只是播放器测试片，**不是所列作品**；图片不是作品封面或演员照片。目录被 Git 忽略，需自己在私有部署中添加，公开 Demo 不读取该目录。
